# OJ_Better

> 自动把 YTUOJ 中「未完成 / 错误」的作业题交给 AI 写代码并提交。

登录 YTUOJ → 找出进行中作业里未通过的题目 → 调用大模型生成代码 → 提交一次 → 退出。

> **只提交一次，不校验是否正确，不做二次修正。**

## 功能

- 账号密码 + 验证码自动识别（ddddocr）登录
- 只处理**进行中**的作业，自动跳过已通过的题目
- 每道未通过题目调用一次大模型生成代码并提交
- 全过程记录日志，题面与生成代码汇总输出

## 环境要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows（已验证） |
| Python | 3.8+ |
| 网络 | **YTU / eduroam / 实验室等免认证校内网络**（个人网络需 CAS 认证，无法登录） |
| 依赖 | `ddddocr==1.6.1`、`openai==2.44.0` |
| 模型 | 任意 OpenAI 兼容接口，默认 `deepseek-v4-pro` |
`
## 快速开始

```bash`
git clone https://github.com/1dEgoRathmi/OJ_Better.git cd OJ_Better
pip install -r requirements.txt
python problem_extractor.py
`

按提示依次输入 **账号 → 密码 → API Key**，之后程序自动运行并退出。

## 工作流程
`

登录页 → 我的竞赛&作业 → 作业题目列表 → 题目详情 → 提交

`
1. 访问 `loginpage.php`，下载 `vcode.php` 验证码并 OCR 识别，POST 提交登录
2. 访问 `contest.php?my`，筛选**进行中**的作业
3. 遍历作业内题目，跳过已完成/已通过的题
4. 抓取题面（描述、输入、输出、样例），调用大模型生成代码
5. 提交一次代码后继续下一题，全部完成即退出

## 输出文件

| 文件 | 内容 |
| --- | --- |
| `all_problems.txt` | 抓取到的题目信息 + AI 生成的题解代码 |
| `oj_extractor.log` | 运行日志（登录、验证码识别、提交结果） |

## 使用限制

- 只提交一次，**不验证正确性**，失败不重试
- 仅适配 YTUOJ（HUSTOJ）页面结构
- 必须使用校内免认证网络，校外需先连 VPN
- 题目较多时会连续提交，请自行控制频率
